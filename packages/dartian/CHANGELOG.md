# Changelog

## 1.0.0

- Initial release
- Umbrella package that re-exports all Dartian components:
  - dartian_core: Core utilities and telemetry
  - dartian_http: HTTP kernel with middleware
  - dartian_router: Fluent routing DSL
  - dartian_di: Dependency injection
  - dartian_orm: Drift-based ORM
  - dartian_redis: Redis client
  - dartian_queue: Job queues
  - dartian_scheduler: Task scheduling
  - dartian_view: Mustache templates
  - dartian_i18n: Internationalization
  - dartian_auth: Authentication
